Se connecter et s’inscrire

Créer son compte, confirmer son adresse, puis se connecter.

Youm s’utilise avec une adresse électronique et un mot de passe. Aucun compte Git n’est nécessaire, y compris pour les profils métier.

Créer un compte

  1. Sur l’écran de connexion, choisissez Créer un compte, sous le formulaire.
  2. Saisissez votre adresse électronique et un mot de passe de 6 caractères au moins.
  3. Validez avec le bouton Créer un compte.

Youm vous envoie alors un courriel de confirmation. Ouvrez le lien qu’il contient pour activer votre compte : tant que l’adresse n’est pas confirmée, la connexion est refusée.

Se connecter

Sur l’écran Connexion, saisissez votre adresse et votre mot de passe, puis choisissez Se connecter.

Le logo et le lien Retour à l’accueil ramènent à la page de présentation de Youm.

Mot de passe oublié

  1. Sur l’écran Connexion, choisissez Mot de passe oublié ?.
  2. Saisissez votre adresse électronique, puis choisissez Envoyer le lien.

Ouvrez le lien reçu par courriel. Youm vous demande votre nouveau mot de passe, puis vous connecte.

Gérer votre compte

Votre pastille, en haut à droite, ouvre Mon compte.

  • Adresse électronique : Modifier ouvre une fenêtre où saisir la nouvelle adresse. Un lien part vers l’ancienne et vers la nouvelle ; l’adresse change une fois les deux confirmés, et vous vous connectez ensuite avec la nouvelle.
  • Mot de passe : Modifier ouvre une fenêtre où saisir le nouveau mot de passe.
  • Double authentification : Activer ouvre une fenêtre avec un code QR. Scannez-le avec une application d’authentification (Google Authenticator, Microsoft Authenticator, 1Password…), puis saisissez le code à 6 chiffres qu’elle affiche. Ensuite, chaque connexion demande ce code après le mot de passe. Désactiver revient au mot de passe seul. Si vous perdez votre téléphone, un administrateur de la plateforme peut réinitialiser votre double authentification.
  • Mes données : Télécharger mes données donne un fichier avec votre adresse, vos organisations, vos rôles et ce que vous avez écrit.
  • Supprimer mon compte, dans la Zone sensible repliée en bas de page : saisissez votre adresse dans la fenêtre de confirmation. La suppression est définitive. Vos stories et commentaires restent dans leurs organisations, sans votre nom. Si vous possédez une organisation, il faut d’abord la transférer ou la supprimer.

Si la connexion est refusée

Youm affiche la raison dans un encadré « Action refusée », sous le formulaire, par exemple « Adresse électronique ou mot de passe incorrect. ». Vérifiez l’adresse saisie, puis votre mot de passe. Si vous venez de vous inscrire, confirmez d’abord votre adresse avec le lien reçu par courriel.

Changer de langue

Le sélecteur FR / EN bascule toute l’interface entre le français et l’anglais. Il se trouve sous la carte des écrans de connexion, d’inscription et de création d’organisation, puis dans la barre du haut une fois dans Youm. Youm retient votre choix sur cet appareil.
